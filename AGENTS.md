# SportNest client

Next.js 16.4 App Router client (React 19, Tailwind v4, shadcn `base-nova`). This repo is the client only — there are no API routes, server actions, or API client yet. The homepage is implemented with dummy data; `/facilities` and `/bookings` are placeholder pages.

## Commands

- `npm run dev` / `npm run build` / `npm run start` — Turbopack is used by default; there is no webpack config.
- `npm run lint` — runs `eslint` with no path, so it lints the repo. The baseline is **not clean**: `src/components/ui/carousel.tsx:98` and `src/hooks/use-mobile.ts:14` fail `react-hooks/set-state-in-effect`. Don't report these as regressions.
- `npx tsc --noEmit` — the only typecheck command; there is no `typecheck` script. `next build` also runs TypeScript.
- No test runner, test script, formatter, or CI config exists. Don't invent test commands.

## Framework quirks

- `next.config.ts` enables `cacheComponents`, `partialPrefetching`, and `reactCompiler`. Cache Components changes caching/PPR behavior; read `node_modules/next/dist/docs/01-app/03-api-reference/05-config/01-next-config-js/cacheComponents.md` before adding data fetching. Don't add `runtime` exports or `experimental.ppr`.
- Next 16 bundles version-matched docs at `node_modules/next/dist/docs/`. Check them before using App Router APIs; training data may be stale.
- Route prop types such as `LayoutProps<"/">` are generated globally by Next. Don't import them, and don't edit `.next/types` or `next-env.d.ts` (gitignored).
- The managed Next.js block at the top of this file is regenerated by `next dev`; keep it and commit it.

## UI and styling

- Tailwind v4: there is no `tailwind.config.*` or PostCSS config. `src/app/globals.css` imports `tailwindcss`, `tw-animate-css`, and `shadcn/tailwind.css`, then defines the light-only navy/emerald theme tokens. Keep the `@theme inline` mappings in sync when adding colors. CSS is wired through the `@tailwindcss/turbopack` loader in `next.config.ts`.
- Homepage dummy data lives in `src/data/home.ts` with types in `src/types/home.ts`. Unsplash images are allowed through `images.remotePatterns` in `next.config.ts`.
- shadcn is configured in `components.json` (style `base-nova`, RSC, lucide icons). Add components with `npx shadcn add <name>`; reuse primitives already in `src/components/ui` instead of hand-rolling them. Those files are generated — `shadcn add --overwrite` replaces local edits.
- Primitives come from `@base-ui/react`, not Radix. Composition uses the `render` prop (`render={<Button />}`), not `asChild`.
- Existing components import `cn` from the `"cn"` package, not `@/lib/utils`. Keep that pattern; `src/lib/utils.ts` is only a re-export.
- UI components set `data-slot="..."` and use `cva` + Tailwind classes. Match that structure when editing.
- Path alias: `@/*` maps to `src/*`.
